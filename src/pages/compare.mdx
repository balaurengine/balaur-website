# Compare

## Side by side

| | Balaur | Godot 4 | Bevy | Fyrox |
| --- | --- | --- | --- | --- |
| Engine language | Rust | C++ | Rust | Rust |
| Game code | Rune scripts; Rust or C plugins | GDScript, C#; Rust or C++ plugins | Rust | Rust |
| Model | A scene tree | A scene tree | ECS | A scene tree |
| Scene format | `.toml`, text | `.tscn`, text | Rust code, or `.ron` | `.rgs` |
| Editor | Yes | Yes | No | Yes |
| Hot reload | Scripts, on save | Scripts, on save | Assets; opt-in code patching | Code, marked experimental |
| Cross-platform determinism | Yes: fixed 60 Hz step, replay, rollback | No | No | No |
| 2D and 3D | Both | Both | Both | Both |
| Platforms | Desktop, mobile, web | Desktop, mobile, web; consoles through partners | Desktop, mobile, web | Desktop, web |
| Networking | HTTP, WebSockets, WebTransport | HTTP, WebSockets, WebRTC, ENet | Community crates | Community crates |
| Licence | MIT | MIT | MIT | MIT |
| Age | Very new | Over a decade | Few years | Few years |

## Memory

What an idle project holds, headless: the number that decides how many instances fit on a server.

| scene | Balaur | Godot 4.7 |
| --- | ---: | ---: |
| empty project | **13 MB** | 41 MB |
| 10,000 nodes | **19 MB** | 67 MB |
| 50,000 nodes | **31 MB** | 166 MB |

Balaur costs about 0.35 KB per node, Godot about 2.5 KB, so the gap widens with the size of the scene.

Physics and scene-tree throughput are on the [benchmarks page](/docs/benchmarks).
