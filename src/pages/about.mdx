# About

Balaur is a 2D & 3D node-based game engine. Deterministic ticks,
Rune scripts that hot reload in milliseconds. Written in Rust. Free, MIT.

## Who

**[Dragos Daian](https://github.com/Ughuuu)**, [appsinacup](https://appsinacup.com).
Created a replacement for Godot Physics using Rapier in Rust and made a Game Server in Elixir.

- [Godot Rapier Physics](https://github.com/appsinacup/godot-rapier-physics):
  Rapier's 2D and 3D physics in Godot.
- [Gamend](https://github.com/appsinacup/gamend), an open source Elixir game
  server: auth, lobbies, leaderboards, payments, server hooks. Balaur's
  [Gamend module](/docs/manual/gamend) talks to it.
- [Godot Box2D](https://github.com/appsinacup/godot-box2d),
  [Godot SoftBody2D](https://github.com/appsinacup/godot-softbody2d),
  [Godot Whisper](https://github.com/appsinacup/godot-whisper). More Godot
  extensions.

**[Sébastien Crozet](https://github.com/sebcrozet)**, [dimforge](https://dimforge.com).
Created Rapier, parry and other important Rust libraries.

- [Rapier](https://rapier.rs): the physics under Balaur, 2D and 3D.
- [Parry](https://parry.rs) is the collision detection under Rapier.
- [kiss3d](https://github.com/dimforge/kiss3d): the renderer under Balaur, uses
  wgpu.
- [nalgebra](https://nalgebra.rs), [salva](https://github.com/dimforge/salva),
  [bevy_rapier](https://github.com/dimforge/bevy_rapier). The rest of dimforge.

Everything else the engine stands on: [Built on](/docs/built-on).

## Why

- Godot Rapier Physics makes the physics in Godot deterministic. The rest of the
  game is not. Balaur makes the **whole tick** deterministic.
- A bug fix in Godot waits on review and a release. Here we ship faster as we own the repositories.
- [From Godot Rapier to Balaur](/blog/godot-rapier-and-balaur).
