<Section title="How it works" sub="Three commands: trace, record, verify.">
  <HowItWorks file="the command line" code={`balaur run my-game --fixed-tick --trace-digest run-a.txt

balaur run my-game --fixed-tick --record session.blr
balaur replay session.blr --verify          # stops at the first tick that disagrees
balaur replay session.blr --entries-at 25   # that tick, one digest per node and component`}>

The engine measures its own determinism: Rapier's enhanced-determinism feature in both worlds, transcendentals on `libm`, a fixed step, and a per-tick digest of every node and component.

Record on one machine, replay on another: the digests either match or the replay names the tick and the node that differ.
