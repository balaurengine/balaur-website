<Section title="Features" sub="Record, replay and verify.">
  <HowItWorks file="terminal" code={`balaur run my-game --fixed-tick --record session.blr

balaur replay session.blr --verify`}>

The engine measures its own determinism:
- Physics are deterministic using the `Rapier` Physics library
- Transcendentals (sin/cos/etc.) use `libm`
- at fixed step, a per-tick digest is computed of every node and component

Record on one machine, replay on another.

  </HowItWorks>
</Section>
