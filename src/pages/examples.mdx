# Examples

Seven projects ship in the [engine repository](https://github.com/balaurengine/balaur/tree/main/examples). Every screenshot and clip in the manual is taken on one of them, so what you see there is what opens here. Balaur builds from source for now — [Getting started](/docs/getting-started) has the toolchain — and each card carries the command that opens its project in the editor.

Each example's scene is plain TOML and its scripts are Rune, so the fastest way to learn the engine is to open one and change something. What the editor's own personas look like on them is on [the editor](/docs/manual/editor) page.
