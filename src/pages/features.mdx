# Features

What is in the engine today, one line each. The why is in [Principles](/docs/principles).

## Nodes, scenes, scripts

- **Scene tree.** Named nodes with scripts, over an ECS you never see. → [Scenes](/docs/manual/scenes)
- **TOML scenes.** Every component is a scene key, a script call and an inspector row at once. → [Scenes](/docs/manual/scenes)
- **Rune.** Rust's syntax, no build step, `async`/`await`. → [Scripting](/docs/manual/scripting)
- **Hot reload.** A saved script is live in milliseconds, state intact. → [Scripting](/docs/manual/scripting#hot-reload)
- **Debugger.** Breakpoints, stepping, frames and locals, in the editor. → [Scripting](/docs/manual/scripting#debugging)
- **Assets.** Content by reference or inline, one rule for every type. → [Assets](/docs/reference/assets)

## Simulation

- **Physics.** 2D and 3D through Rapier, on a fixed 60 Hz step. → [Physics](/docs/manual/physics)
- **Animation.** Clips, tweens, twelve easings, method tracks. → [Animation](/docs/manual/animation)
- **Skeletons.** 2D bones with skinned polygons, 3D rigs from glTF, look-at and two-bone IK. → [Animation](/docs/manual/animation#skeletons-and-skins)
- **Determinism.** Same inputs, same bits everywhere; per-tick digests, record and replay, rollback. → [Determinism](/docs/manual/determinism)

## Screen and sound

- **Rendering.** 3D and 2D on wgpu — windowed, offscreen, or headless — with sprites, tile maps, particles and meshes.
- **UI.** Widgets for HUDs, an immediate-mode API for tools. → [UI](/docs/manual/ui)
- **Audio and input.** rodio playback; keyboard, mouse, gamepads, touch. → [Input](/docs/manual/input)

## Online

- **Networking.** HTTP and websockets with compression, delivered once per tick and replayable. → [Networking](/docs/manual/networking)
- **Gamend.** Login, REST, realtime rooms, server hooks. → [Gamend](/docs/manual/gamend)

## Tools and shipping

- **The editor.** A Balaur project itself: tree, inspector, gizmos, timeline, rig tools, play-in-editor, undo. → [The editor](/docs/manual/editor)
- **Editor plugins.** Docks, tools, commands and inspector sections from a project's own Rune files. → [Extending the editor](/docs/manual/editor#extending-the-editor)
- **Extensions.** Plugins linked in or loaded at run time. → [Extensions](/docs/manual/extensions)
- **Packs.** Reproducible exports with bytecode, scenes and assets. → [Shipping](/docs/manual/shipping)
- **One executable.** A pack fused onto a runtime; no compiler, no sources. → [Shipping](/docs/manual/shipping)
- **Platforms.** Desktop today; iOS, Android and WebAssembly compile in CI on every push.
- **Built on Rust.** Safe code and the ecosystem as it is. → [Built on](/docs/built-on)
