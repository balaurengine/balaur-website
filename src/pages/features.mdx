# Features

The engine features. See also [Principles](/docs/principles).

<FeatureGroup title="Nodes, scenes, scripts" clip="scenes_inspect" alt="Selecting a node in the tree and editing it in the inspector" to="/docs/manual/scenes" toLabel="Scenes and nodes">
  <Feature icon="tree-structure" to="/docs/manual/scenes"><strong>Scene tree.</strong> Nodes with scripts attached.</Feature>
  <Feature icon="code" to="/docs/manual/scripting"><strong>Rune.</strong> Rust's syntax, `async`/`await`. Instant reload.</Feature>
  <Feature icon="bug" to="/docs/manual/scripting#debugging"><strong>Debugger.</strong> Breakpoints, stepping, frames and locals, in the editor.</Feature>
  <Feature icon="package" to="/docs/reference/assets"><strong>Assets.</strong> Content referenced by a node.</Feature>
</FeatureGroup>

<FeatureGroup title="Simulation" side="right" clip="determinism_replay" alt="Recording a session and replaying it tick by tick to the same result" to="/docs/manual/determinism" toLabel="Determinism">
  <Feature icon="atom" tone="3d" to="/docs/manual/physics"><strong>Physics.</strong> 2D and 3D through Rapier, on a fixed 60 Hz step.</Feature>
  <Feature icon="film-strip" tone="animation" to="/docs/manual/animation"><strong>Animation.</strong> Clips, tweens and easing.</Feature>
  <Feature icon="bone" tone="animation" to="/docs/manual/animation#skeletons-and-skins"><strong>Skeletons.</strong> Bones with skinned polygons.</Feature>
  <Feature icon="arrows-clockwise" tone="physics" to="/docs/manual/determinism"><strong>Determinism.</strong> Same inputs, same outputs, on every platform.</Feature>
</FeatureGroup>

<FeatureGroup title="Screen and sound" clip="shader_preview" alt="A material's shader edited and previewed in the editor" to="/docs/manual/rendering" toLabel="Rendering">
  <Feature icon="image" tone="render" to="/docs/manual/rendering"><strong>Rendering.</strong> 2D and 3D.</Feature>
  <Feature icon="shapes" tone="3d" to="/docs/manual/scenes/#objects"><strong>Objects.</strong> Basic primitives, bezier paths, text and boolean operations.</Feature>
  <Feature icon="grid-four" tone="2d" to="/docs/manual/tiles"><strong>Tile maps.</strong> Solid, one-way, animated and light-blocking tiles.</Feature>
  <Feature icon="sun" tone="render" to="/docs/manual/rendering"><strong>Lights.</strong> 2D lights and occluders, with post-processing on top.</Feature>
  <Feature icon="paint-brush" tone="render" to="/docs/manual/shaders"><strong>Shaders.</strong> Materials written in WESL.</Feature>
  <Feature icon="layout" tone="ui" to="/docs/manual/ui"><strong>UI.</strong> Widgets and an immediate-mode API for tools.</Feature>
  <Feature icon="text-aa" tone="ui" to="/docs/manual/text"><strong>Text.</strong> Outline, shadow, markup and bitmap fonts.</Feature>
  <Feature icon="speaker-high" tone="audio" to="/docs/manual/input"><strong>Audio and input.</strong> audio playback; keyboard, mouse, gamepads, touch inputs.</Feature>
</FeatureGroup>
