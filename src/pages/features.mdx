# Features

Everything in the engine today. Each item links into the documentation.

## Core

- **Scene tree over an ECS.** A game is a tree of named nodes with scripts
  attached; every node is a `hecs` entity, and every subsystem is a plugin
  over the same data plane. Node paths, transform propagation, and a fixed
  frame schedule are core systems. → [Scenes and nodes](/docs/manual/scenes)
- **Declarative scenes.** Scenes are TOML; plugins extend the vocabulary with
  schema-described components, and one registration buys the scene key, the
  runtime API, and editor support at once. → [Scenes and nodes](/docs/manual/scenes)
- **Shared assets.** Content by reference or inline — a string is a
  reference, a table is a definition — for every asset type a plugin
  registers. → [Assets](/docs/reference/assets)
- **Headless by default.** Everything runs without a window or GPU: tests,
  servers, CI, and benchmarks measure the engine itself.

## Scripting

- **Two languages, one API.** Luau (default) and Rune call the same bindings,
  declared once against a language-neutral seam; a third language costs one
  crate. A project can even run both at once (`language = "mixed"`), with
  cross-language calls by node and method name.
  → [Scripting](/docs/manual/scripting)
- **Instant hot reload.** Saving a script swaps code into the running game in
  milliseconds, preserving live state — automatic, always on in dev mode,
  provided by the core. → [Scripting](/docs/manual/scripting)
- **Events without signals.** The engine calls handler methods scripts
  declare by name, and async results can be `await`ed sequentially; both
  arrive deterministically at the start of a tick.
  → [Networking](/docs/manual/networking)

## Simulation

- **3D and 2D physics.** Rapier with `enhanced-determinism`, both worlds on a
  fixed 60 Hz step, declared in scenes or driven from scripts.
  → [Physics](/docs/manual/physics)
- **Animation.** Clip assets with transform, component-property, and method
  tracks; script-driven tweens through the same sampler; twelve easing
  curves; all on a fixed timestep. → [Animation](/docs/manual/animation)
- **Skeletons.** 2D bones with GPU-skinned textured polygons, 3D bones with
  skinned meshes imported from glTF, `look_at` and two-bone IK modifiers —
  all keyed by the same clips. → [Animation](/docs/manual/animation#skeletons-and-skins)
- **Cross-platform determinism.** Identical inputs produce bit-for-bit
  identical simulations on every platform: a fixed 60 Hz `fixed_update`,
  seeded RNG, `libm` transcendentals, ordered collections, per-tick digests,
  session recording and replay, and rollback snapshots.
  → [Determinism](/docs/manual/determinism)

## Interface

- **Rendering.** 3D and 2D shapes through kiss3d/wgpu in three run modes —
  windowed, offscreen (GPU without a window), and headless — with cameras,
  debug drawing, grids, and script-driven screenshots
  (`render.screenshot`).
- **UI.** Widget components for in-game HUDs, and an immediate-mode egui API
  for scripts with script-defined themes. → [UI](/docs/manual/ui)
- **Audio and input.** rodio-backed playback; backend-agnostic per-frame
  input snapshots covering keyboard, mouse, gamepads, touch, and files
  dropped onto the window. → [Input](/docs/manual/input)

## Online

- **Networking.** HTTP requests and websocket connections for scripts, on
  background threads, delivered into the simulation once per tick.
  → [Networking](/docs/manual/networking)
- **Gamend backend.** Login, REST, realtime rooms, and server hooks on the
  same delivery contract. → [Gamend](/docs/manual/gamend)

## Tooling

- **An editor that is a Balaur project.** Scene tree, generated inspector,
  viewport gizmos in 3D and 2D, undo, script editing with hot reload and a
  debugger, play-in-editor, a clip timeline, and bone and polygon tools —
  built entirely on the public scripting surface.
  → [The editor](/docs/manual/editor)
- **Extensions.** The same `Plugin` trait ships linked in behind a cargo
  feature or as a shared library loaded at run time — written in Rust against
  the exact engine build, or in any C-ABI language through a small stable C
  boundary. → [Modules and extensions](/docs/manual/extensions)
- **Benchmarks.** A headless suite reporting each result as a share of one
  60 fps frame, running the same scenarios on both script languages.
  → [Getting started](/docs/getting-started#benchmarks)

## Shipping

- **Reproducible packs.** Export compiles scripts to bytecode and bundles
  them with scenes and assets; the same sources give the same bytes on any
  machine. → [Shipping](/docs/manual/shipping)
- **One executable.** Fusing a pack onto a runtime template produces a single
  binary per platform — no compiler, no sources, no Rust toolchain required
  to ship. CI cross-compiles the headless engine to iOS, Android, and
  WebAssembly on every push. → [Shipping](/docs/manual/shipping)
- **Saved data.** `engine.user_data_dir()` gives every game a writable
  per-user directory for saves and settings, resolved per platform.
