<Section title="How it works" sub="A clip is TOML you can read and diff.">
  <HowItWorks file="animations/platform.toml" code={`type = "animation_clip"

[clips.patrol]
length = 4.0
loop = "pingpong"

[[clips.patrol.tracks]]
property = "position"      # position | rotation_euler | rotation | scale | <component>/<property>
interp = "linear"          # step | linear | cubic
keys = [
  { t = 0.0, value = [-2.5, 0.25, -2.0] },
  { t = 4.0, value = [-2.5, 0.25, 2.0], ease = "in_out_sine" },
]

[[clips.patrol.tracks]]
keys = [{ t = 4.0, call = "on_reached_end" }]   # a method track`}>

A clip is a length, what to do with time past it (none, loop or pingpong), and a list of tracks. Each track addresses a property by path and keys it; a method track calls a script function. A library file holds several clips under `[clips.<name>]`.

A bone is any node carrying `bone2d` or `bone3d`, so the tree is the rig and the same clip keys bones by path.

  </HowItWorks>
</Section>
