<Section title="Components" sub="Build everything with nodes and components.">
  <HowItWorks file="animations/platform.toml" code={`type = "animation_clip"

[clips.patrol]
length = 4.0
loop = "pingpong"

[[clips.patrol.tracks]]
property = "position"
interp = "linear"
keys = [
  { t = 0.0, value = [-2.5, 0.25, -2.0] },
  { t = 4.0, value = [-2.5, 0.25, 2.0], ease = "in_out_sine" },
]

[[clips.patrol.tracks]]
keys = [{ t = 4.0, call = "on_reached_end" }]`}>

A bone is any node carrying `bone2d` or `bone3d`, so the tree is the rig and the same clip keys bones by path.

Animations are keyframes that say when a property needs to change, and how.
