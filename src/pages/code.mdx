<Section title="How it works" sub="A scene is a file you can read, and a component shows up in three places at once.">
  <HowItWorks file="scenes/main.toml" code={`[[nodes]]
name = "Ball"
position = [0.0, 6.0, 0.0]
script = "scripts/ball.rn"
body3d = "dynamic"
collider3d = { kind = "ball", radius = 0.5 }
shape3d = { kind = "ball", radius = 0.5 }`}>

`body3d`, `collider3d` and `shape3d` are components the physics and render plugins registered. That one registration makes them scene keys, script calls and inspector rows together: no binding step, no generated glue to keep in sync.

Scripts are [Rune](https://rune-rs.github.io): Rust's syntax, no build step, `async`/`await`. A script is a file attached to a node, with `init`, `update` and whatever methods the scene calls.

  </HowItWorks>
</Section>
