# Community

## Talk

- [Discord](https://discord.gg/v649emcpAu) for questions, screenshots, what
  broke. Fastest way to reach anyone.
- [Discussions](https://github.com/balaurengine/balaur/discussions): ideas
  and proposals. Propose here before building anything large.
- [Issues](https://github.com/balaurengine/balaur/issues) for bugs, one per
  issue.

## Follow

- [Blog](/blog): what shipped and why.
  <a href="pathname:///blog/rss.xml">RSS</a> · <a href="pathname:///blog/atom.xml">Atom</a>.
- [Roadmap](/docs/roadmap): what is missing.
- Watch the [repo](https://github.com/balaurengine/balaur) for release tags.

## Help without engine code

- Build from source, run the [examples](/examples), report what your OS, GPU or
  gamepad did differently.
- Bug reports: the scene or script that reproduces it, expected, actual,
  platform.
- Fix the docs: *Edit this page* at the bottom of every page.
- Answer someone in the Discord.

## Help with the engine

- [CONTRIBUTING.md](https://github.com/balaurengine/balaur/blob/main/CONTRIBUTING.md):
  build, test, lint.
- [ARCHITECTURE.md](https://github.com/balaurengine/balaur/blob/main/ARCHITECTURE.md)
  before changing the shape of anything; [Principles](/docs/principles) for how
  the project is run.
- Large changes: a [Discussion](https://github.com/balaurengine/balaur/discussions)
  first.
- Every change is complete: code, tests, docs, and the roadmap row it moves.
  Generated docs regenerated.
- Determinism is a hard gate. A changed checksum needs a reason.
- One concern per pull request. [CI](/docs/quality) enforces lints and style.
- AI-assisted contributions welcome, at the same bar.
