# Introduction

Balaur is a node-based 2D and 3D game engine: scripting, physics, animation,
networking, and an editor. Written in Rust.

A game is a scene tree of named nodes with scripts attached. Underneath,
every node is an ECS entity and every subsystem is a plugin. The editor is
itself a Balaur project.

![The editor: scene tree, viewport, inspector](/img/manual/editor_overview.webp)

:::warning

No published release yet. Balaur builds from source: see
[Getting started](./getting-started.mdx).

:::

## Hot reload and determinism

- Instant hot reload. Save a script while the game runs; the new code is
  live in milliseconds and the state survives.
- Determinism, always on. Same inputs, same bits on every platform: a fixed
  60 Hz step, a digest per tick, record and replay. Network replies land at
  the start of a tick in arrival order, so a replay covers logins and retries.

## A script

```rune
// scripts/spinner.rn
pub fn init(this) { this.angle = 0.0; }

pub fn update(this, dt) {
    this.angle += dt;
    this.node.set_rotation_euler(0.0, this.angle, 0.0);
}
```

## A scene

```toml
[[nodes]]
name = "Ball"
position = [0.0, 6.0, 0.0]
script = "scripts/ball.rn"
body3d = "dynamic"
collider3d = { kind = "ball", radius = 0.5 }
shape3d = { kind = "ball", radius = 0.5 }
```

`body3d`, `collider3d` and `shape3d` are components. The physics and render
plugins registered them, which also made them script calls and inspector rows.
