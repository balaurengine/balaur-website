# Introduction

Balaur is a deterministic node-based 2D and 3D game engine. A game is a scene tree of nodes with scripts attached.

![The editor: scene tree, viewport, inspector](/img/manual/editor_overview.webp)

## Hot reload and determinism

- Instant hot reload. Save a script and it reloads instantly.
- Determinism, always on. Same inputs, same outputs on every platform.

## A script

```rune
// spinner.rn
pub fn init(this) { this.angle = 0.0; }

pub fn update(this, dt) {
    this.angle += dt;
    this.node.transform.rotation_euler = [0.0, this.angle, 0.0];
}
```

## A scene

```toml
# scene.toml
[[nodes]]
name = "Ball"
script = "scripts/ball.rn"
transform = { position = [0.0, 6.0, 0.0] }
body3d = "dynamic"
collider3d = { kind = "ball", radius = 0.5 }
shape3d = { kind = "ball", radius = 0.5 }
```

This scene has a node called Ball with four components: `transform`, `body3d`, `collider3d` and `shape3d`.
