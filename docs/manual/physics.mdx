# Physics

A plugin wrapping [Rapier](https://rapier.rs): rapier3d for `body3d` and
`collider3d`, rapier2d for `body2d` and `collider2d`. Both worlds run over
the same scene tree, built with Rapier's `enhanced-determinism` feature,
stepped on a fixed 60 Hz tick.

## Declaring bodies

```toml
[[nodes]]
name = "Crate"
transform = { position = [0, 3, 0] }
body3d = { kind = "dynamic" }      # dynamic | kinematic | static
collider3d = { kind = "cuboid", half_extents = [0.5, 0.5, 0.5] }
```

```rune
physics3d::add_body(this.node, physics3d::BODY_DYNAMIC);
physics3d::add_ball_collider(this.node, 0.5);

physics2d::add_body(this.node, physics2d::BODY_DYNAMIC);
physics2d::add_collider(this.node, #{ kind: physics2d::SHAPE_RECT, half_extents: [0.5, 0.5] });
```

- A collider takes `kind` (`ball` and `cuboid` in 3D, `circle` and `rect` in
  2D, and a dozen more each) with the matching dimensions.
- Plus `restitution`, `friction` and `density`.
- Scene keys and script constants use the same names.

## Component handles

```rune
physics2d::apply_impulse(this.node, 1.0, 0.0);
this.node.body2d.apply_impulse(1.0, 0.0);
```

- Every function takes the node first and is also a method on the node's
  component handle.
- `node.body2d` binds to the module that drives the component.
  `apply_impulse` on a `body3d` handle reaches `physics3d`.
- Handles also carry `get()`, `set(table)`, `has()` and `remove()`.
- A method no module declared for the component is an error naming it
  (`node.sprite.apply_impulse`).
- Each component's methods are on its reference page, for example
  [`body2d`](/docs/reference/components/body2d).

## Driving the simulation

| Module | What is in it |
| --- | --- |
| `physics3d`, `physics2d` | Bodies, colliders, joints, velocities and queries, one module per world |
| `physics2d` only | `max_contact_impulse(node)`, the strongest impact a body took this frame |
| `physics` | Both worlds: `set_paused`, `is_paused`, `clear`, `set_sleeping_allowed`, `sleeping_allowed`, the debug draw, the solver's tuning and counters |

The editor pauses physics until play. Its Physics persona draws every body's
collider and centre of mass over the scene, playing or not.

## Determinism

- Physics steps on a fixed 60 Hz tick.
- Order-sensitive collections iterate deterministically.
- Two runs with identical inputs match bit for bit. See
  [Determinism](./determinism.mdx).
