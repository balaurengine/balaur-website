# Build size

The engine module is most of a web game's download. The numbers below are the
module behind [the editor](/editor) and the playable [examples](/examples),
measured on every deploy.

<PlaySize />

- The host decides which number a player downloads: brotli when it compresses
  `.wasm` (see the `content-encoding` header), gzip when it only does that,
  raw when it does neither.
- The browser compiles the raw size either way.
- The pack, the game's own bytes, is on top.

## Module contents

One module carries the whole engine; nothing loads lazily. In it:

- the renderer: wgpu with both its WebGPU and WebGL2 backends, naga, winit;
- the UI: egui and its four default fonts, its `vello_cpu` rasteriser, and a
  second text shaper for marked-up text;
- physics in both dimensions, rapier and parry;
- the Rune compiler and VM;
- every audio codec rodio turns on, and every image format kiss3d turns on.

| section | share |
| --- | ---: |
| code | 76% |
| data | 24% |

Code by crate, from the same build with symbols kept. Each function is charged
to its defining crate; 2% of the code names no crate.

| | MB |
| --- | ---: |
| the engine's own crates | 2.4 |
| egui's CPU rasteriser, through `epaint` | 1.9 |
| Rune, the compiler and the VM | 1.6 |
| the renderer: wgpu, naga, winit | 1.3 |
| text shaping and font parsing, two stacks | 1.1 |
| the WESL compiler, which runs at load | 0.9 |
| physics in 3D | 0.8 |
| physics in 2D | 0.7 |
| image codecs | 0.5 |
| audio codecs | 0.4 |

Those ten are three quarters of the code. The rest is `core`, `alloc` and the
serialisation crates. The rasteriser is `epaint` 0.36 drawing through
`vello_cpu`.

A game carries all of it whichever features it uses; the template is
prebuilt. Half the data is assets baked in by dependencies.

| Baked in by a dependency | Raw | Brotli |
| --- | --- | --- |
| egui's default fonts: Hack, Ubuntu Light, Noto Emoji, emoji-icon | 1.4 MB | 0.7 MB |
| kiss3d's tonemapping lookup table, `tony_mc_mapface.bin` | 0.9 MB | 0.2 MB |
| kiss3d's debug-text font, Work Sans | 0.1 MB | 0.05 MB |

The other half is tables: Unicode data for two text shapers, codec tables,
shader sources. Every figure on this page is from that module and moves with
the dependency versions.

## Pack size

The pack is the second download. Every export prints a report.

```text
pack 2.0 MB
section                                 entries      bytes
manifest                                      1       78 B
scenes                                        1     3.4 KB
scripts                                      37   488.2 KB
assets                                        6     1.6 MB

extension                               entries      bytes
ttf                                           4     1.5 MB
png                                           2    22.7 KB

largest                                              bytes
fonts/icons-Phosphor.ttf                          477.2 KB
fonts/ui-SourceSans3-Regular.ttf                  421.1 KB
fonts/heading-SourceSans3-Semibold.ttf            415.9 KB
assets/balaur-logo.png                             20.2 KB

0 files nothing references, 0 B
```

- Fonts outweigh images in most projects, and the engine outweighs both.
- On the engine's own assets, subsetting takes a 421 KB face to 29 KB and the
  image pass takes a small sprite from 1.1 KB to 0.5 KB.
- Four `[export]` keys act on the report, each off by default.

![Where a pack's bytes are, and what lossless re-encoding takes off](/img/manual/export_size.webp)

```toml
[export]
strip = true                # drop an asset no scene, script or keep glob names
keep = ["sfx/**"]           # ...except paths a script builds at run time
images = "smallest"         # recompress PNG, or write lossless WebP, whichever wins
fonts = "subset"            # cut a face to the characters the project actually shows
font_keep = ["fonts/ui-*"]  # ...but ship these whole
audio = "flac"              # write uncompressed WAV as lossless FLAC
```

Anything under `fonts/` survives a strip: the UI finds faces by listing that
directory, and no scene names one.

Two more keys are lossy, and named separately from the lossless ones.

```toml
[export]
images = "quantised"    # a 256-colour palette with alpha, then the PNG pass
images_quality = 80     # the palette's quality target, 0 to 100
audio = "vorbis"        # an Ogg Vorbis stream instead of the original PCM
audio_quality = 0.5     # libvorbis quality, -0.1 to 1.0
```

One picture overrides the mode in its own
[import settings](/docs/manual/scenes#import-settings).

```toml
# art/logo.png.toml
recode = "keep"     # this one ships exactly as drawn
```

- Every mode except `quantised` and `vorbis` is lossless. None changes a pixel
  count.
- A sprite is sized from its image header; a re-encoded texture is the same
  sprite.
- `balaur export --report` prints the table and writes nothing.
- An atlas is not a size lever: it saves each file's header and little else.
  The renderer draws one call per node either way.
- GPU-compressed textures (BC, ETC2, ASTC) cut video memory and upload time,
  not the download. A block-compressed image on disk is larger than the PNG it
  came from.

## Building a smaller template

`balaur export --target web` copies a template (the glue and module
`scripts/package_template.sh web` builds in the engine repository) and puts
the pack and a page beside it. A template built with fewer features is passed
to the exporter.

```bash
WEB_FEATURES=window,web scripts/package_template.sh web
balaur export my-game --target web --template dist/balaur-template-web
```

- The script needs the `wasm32-unknown-unknown` target, the `wasm-bindgen`
  CLI at the version in `Cargo.lock` (checked), `wasm-opt` from binaryen, and
  `brotli` for the size line it prints.
- It refuses a module under 5 MB: a build whose entry point was optimised
  away.
- On a browser build only `audio` and `window` weigh anything.
- Every other feature gates its native stack off the wasm target and costs
  the plugin's own code.

## Dependency levers

These are dependency lines in the engine, not cargo features. A fork can flip
each; sizes are given where measured.

- egui's default fonts. `egui` is built with `default_fonts` on, by
  `balaur_ui` and by kiss3d; the UI plugin falls back to them when a project
  ships no `fonts/*.ttf`. A game with its own fonts carries both sets: 1.4 MB
  raw, 0.7 MB brotli.
- The WebGL2 fallback. `egui-wgpu`'s default features turn on `wgpu/webgl`:
  the GLES backend (`glow`) and naga's GLSL writer beside WebGPU. For browsers
  without WebGPU. Unmeasured.
- Image formats. kiss3d enables every format `image` has: decoders for EXR,
  TIFF, GIF, QOI and more. A pack's textures are PNG, JPEG or WebP.
  Unmeasured; EXR alone is a large decoder.
- Audio codecs. rodio's defaults are FLAC, MP3, MP4/AAC, Vorbis and WAV, plus
  dithering noise and a recording path. One feature per codec would let a
  game drop the rest. Unmeasured.
- Physics in one dimension. `balaur_physics` links both rapier2d and
  rapier3d; a 2D game carries the 3D solver and parry3d. The crate is 3D-first
  with `dim2` as a module, so a split is a refactor. parry's `parallel`
  feature is on, and rayon has no threads in a browser.
- The tonemapping table. 0.9 MB raw, 0.2 MB brotli, for HDR tonemapping in
  kiss3d. An analytic curve costs no bytes.
- Two text shapers. epaint shapes with `harfrust` 0.12; `cosmic-text`
  (marked-up text in `balaur_ui`) with `harfrust` 0.5. Two copies of the
  shaping tables, `read-fonts` and `skrifa` are linked until the versions
  agree.

The `web` profile in the engine's `Cargo.toml` sets `opt-level = "z"`, fat
LTO, one codegen unit, `panic = "abort"` and stripped symbols, and the script
runs `wasm-opt -Oz` after bindgen. `-Zbuild-std` with `panic_immediate_abort`
would cut more and needs nightly, which the pinned toolchain rules out.
