# Build size

A web game is a download before it is a game, and the engine module is most of
that download. This is the module behind [the editor](/editor) and the playable
[examples](/examples), measured on every deploy.

<PlaySize />

- Which number a player waits for depends on the host: brotli when it
  compresses `.wasm` (check the `content-encoding` header), gzip when it only
  does that, raw when it does neither.
- The raw size is what the browser compiles either way.
- The pack is on top, and it is the game's own bytes.

## Where the bytes go

One module carries the whole engine, and nothing in it loads lazily. In it:

- the renderer: wgpu with both its WebGPU and WebGL2 backends, naga, winit;
- the UI: egui and its four default fonts, plus a second text shaper for
  marked-up text;
- physics in both dimensions, rapier and parry;
- the Rune compiler and VM;
- every audio codec rodio turns on, and every image format kiss3d turns on.

Code is about three quarters of the module and data the rest.

| section | share |
| --- | ---: |
| code | 74% |
| data | 25% |

Where that code goes, read off a build that keeps its symbols. Around a
quarter of the symbols name no crate, so each line is a floor, not a total.

| | MB |
| --- | ---: |
| Rune, the compiler and the VM | 2.2 |
| egui's CPU rasteriser, through `epaint` | 1.5 |
| the WESL compiler, which runs at load | 1.4 |
| text shaping and font parsing, two stacks | 1.3 |
| physics in 3D | 0.8 |
| physics in 2D | 0.5 |
| image codecs | 0.4 |
| audio codecs | 0.2 |

A game pays for all of it whichever features it uses, because the template is
prebuilt. Half the data is assets that dependencies bake in.

| Baked in by a dependency | Raw | Brotli |
| --- | --- | --- |
| egui's default fonts: Hack, Ubuntu Light, Noto Emoji, emoji-icon | 1.4 MB | 0.7 MB |
| kiss3d's tonemapping lookup table, `tony_mc_mapface.bin` | 0.9 MB | 0.2 MB |
| kiss3d's debug-text font, Work Sans | 0.1 MB | 0.05 MB |

The other half is tables: Unicode data for two text shapers, codec tables,
shader sources. Figures are from the nightly of 2026-09-05, and they move with
the dependency versions.

## What your own game weighs

The engine module is one download, and the pack beside it is the other. Every
export prints what it built, so a decision comes with a number attached.

```text
pack 2.0 MB
section                                 entries      bytes
manifest                                      1       78 B
scenes                                        1     3.4 KB
scripts                                      37   488.2 KB
assets                                        6     1.6 MB

extension                               entries      bytes
ttf                                           4     1.5 MB
png                                           2    22.7 KB

largest                                              bytes
fonts/icons-Phosphor.ttf                          477.2 KB
fonts/ui-SourceSans3-Regular.ttf                  421.1 KB
fonts/heading-SourceSans3-Semibold.ttf            415.9 KB
assets/balaur-logo.png                             20.2 KB

0 files nothing references, 0 B
```

- Fonts outweigh images in most projects, and the engine outweighs both.
- On the engine's own assets, subsetting takes a 421 KB face to 29 KB, and the
  image pass takes a small sprite from 1.1 KB to 0.5 KB.
- Four keys in `[export]` act on what the report shows, each off until you
  turn it on.

![Where a pack's bytes are, and what lossless re-encoding takes off](/img/manual/export_size.webp)

```toml
[export]
strip = true                # drop an asset no scene, script or keep glob names
keep = ["sfx/**"]           # ...except paths a script builds at run time
images = "smallest"         # recompress PNG, or write lossless WebP, whichever wins
fonts = "subset"            # cut a face to the characters the project actually shows
font_keep = ["fonts/ui-*"]  # ...but ship these whole
audio = "flac"              # write uncompressed WAV as lossless FLAC
```

Anything under `fonts/` survives a strip whatever the references say, because
the UI finds faces by listing that directory and no scene ever names one.

Two more keys give up fidelity for size. They are named separately, so a
lossless setting can never quietly become a lossy one.

```toml
[export]
images = "quantised"    # a 256-colour palette with alpha, then the PNG pass
images_quality = 80     # the palette's quality target, 0 to 100
audio = "vorbis"        # an Ogg Vorbis stream instead of the original PCM
audio_quality = 0.5     # libvorbis quality, -0.1 to 1.0
```

One picture opts out, or asks for something else, in its own
[import settings](/docs/manual/scenes#import-settings).

```toml
# art/logo.png.toml
recode = "keep"     # this one ships exactly as drawn
```

- Every mode except `quantised` and `vorbis` is lossless, and none changes a
  pixel count.
- A sprite is sized from its image header, so a re-encoded texture is the same
  sprite and the game computes the same world.
- `balaur export --report` prints the table and writes nothing, so a saving is
  visible before it is taken.

Two things the report will not do:

- An atlas is not a size lever. It saves each file's header and little else,
  and the renderer draws one call per node either way.
- GPU-compressed textures (BC, ETC2, ASTC) cut video memory and upload time,
  not the download. A block-compressed image on disk is larger than the PNG it
  came from.

## Building a smaller template

`balaur export --target web` copies a template, the glue and module
`scripts/package_template.sh web` builds in the engine repository, and puts
the pack and a page beside them. Build one with fewer features and hand it to
the exporter.

```bash
WEB_FEATURES=window,web scripts/package_template.sh web
balaur export my-game --target web --template dist/balaur-template-web
```

- The script wants the `wasm32-unknown-unknown` target, the `wasm-bindgen` CLI
  at the version in `Cargo.lock` (it checks), `wasm-opt` from binaryen, and
  `brotli` for the size line it prints.
- It refuses a module under 5 MB, which is what a build whose entry point was
  optimised away looks like.
- On a browser build only `audio` and `window` weigh anything, and a game
  without a window is not a game.
- Everything else keeps its native stack off the wasm target and costs only
  the plugin's own code.

## What is not a feature yet

The levers below are dependency lines in the engine, not switches. Each is
named so a fork can flip it, with a size where one has been measured.


- egui's default fonts. `egui` is built with `default_fonts` on, by
  `balaur_ui` and by kiss3d, and the UI plugin falls back to them when a project
  ships no `fonts/*.ttf`. A game that ships its own carries both sets: 1.4 MB
  raw, 0.7 MB brotli, for nothing.
- The WebGL2 fallback. `egui-wgpu`'s default features turn on
  `wgpu/webgl`, which links the GLES backend (`glow`) and naga's GLSL writer
  beside WebGPU. Current browsers ship WebGPU; the fallback is for older ones.
  Unmeasured.
- Image formats. kiss3d enables every format `image` has, so the module
  links decoders for EXR, TIFF, GIF, QOI and more that no pack uses: a pack's
  textures are PNG, JPEG or WebP. Unmeasured; EXR alone is a large decoder.
- Audio codecs. rodio's defaults are FLAC, MP3, MP4/AAC, Vorbis and WAV,
  plus dithering noise and a recording path. One feature per codec would let a
  game that ships Ogg Vorbis drop the rest. Unmeasured.
- Physics in one dimension. `balaur_physics` links both rapier2d and
  rapier3d, so a 2D game carries the 3D solver and parry3d. The crate is written
  3D-first with `dim2` as a module, which makes a split a refactor rather than a
  flag. parry's `parallel` feature is on too, and rayon has no threads to use in
  a browser.
- The tonemapping table. 0.9 MB raw, 0.2 MB brotli, for HDR tonemapping
  in kiss3d. An analytic curve costs no bytes.
- Two text shapers. epaint shapes with `harfrust` 0.12; `cosmic-text`,
  which `balaur_ui` uses for marked-up text, with `harfrust` 0.5. Two copies
  of the shaping tables, and of `read-fonts` and `skrifa`, are linked until
  the two agree on a version.

What is already done leaves no knob on stable Rust: the `web` profile in the
engine's `Cargo.toml` sets `opt-level = "z"`, fat LTO, one codegen unit,
`panic = "abort"` and stripped symbols, and the script runs `wasm-opt -Oz` after
bindgen. A `-Zbuild-std` with `panic_immediate_abort` would take a further slice
and needs nightly, which the pinned toolchain rules out.
