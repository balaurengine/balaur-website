# Principles

1. **Fast to run**. Performance is important.
2. **Fast to iterate**. Scripts must reload instantly.
3. **Easy to use**. Nodes and scripts on top. With a lot of tools.

The practical version (how to build, test and lint) is
[CONTRIBUTING.md](https://github.com/balaurengine/balaur/blob/main/CONTRIBUTING.md)
in the engine repository.
