# Roadmap

## Where the engine stands

The core loop is in place: scene tree over an ECS, scripting in Luau and Rune
with hot reload and a debugger, 3D and 2D physics, rendering (windowed,
offscreen and headless), animation with clip assets, tweens and 2D and 3D
skeletons, glTF import, a shared-asset layer, networking (HTTP, websockets,
and the Gamend backend), audio, input, UI, run-time extensions, a working
editor with play-in-editor, undo, a clip timeline and rig tools, a fixed
60 Hz simulation step with per-tick digests, session recording and replay,
rollback snapshots, reproducible pack export with binary assets, and fused
single-file executables. CI cross-compiles the headless engine to iOS,
Android, and WebAssembly on every push. There is no binary release yet; the
engine builds from source.

## Next

1. Editor plugins: tools, docks and inspector sections registered from a
   project's own scripts. The editor is already a Balaur project; what
   remains is the registration seam.
2. Animation blending — blend trees and state machines composed over the
   pure sampler — and 3D modifiers to match the 2D `look_at` and
   `two_bone_ik`.
3. `--!strict` type checking surfaced in editor diagnostics; palette-driven
   node search; multi-scene tabs.
4. Prefabs/sub-scenes. The asset layer landed, so a prefab is another
   registered asset type; what remains is the scene key that instantiates one
   and the rule for overriding properties on the instance.
5. GPU skinning for 3D meshes; they are skinned on the CPU today.
6. Parallel system execution inside the data plane, once profiling demands
   it.
