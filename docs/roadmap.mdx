# Roadmap

What we want to add, and for each the one step that comes next. The engine
already has its core loop — nodes over an ECS, Rune with hot reload and a
debugger, 2D and 3D physics, rendering in three modes, animation and
skeletons, networking, an editor that is itself a Balaur project, a fixed
step with record and replay, and reproducible packs. There is no binary
release yet.
