# Roadmap

## Milestones

| | Goal | State |
|---|---|---|
| M0 | A sprite whose script can be edited and reloaded without losing play state | In progress |
| M1 | A 2D game buildable from the command line: tilemaps, physics, audio, animation, HUD | Not started |
| M2 | Editor: scene tree, inspector, viewport, play-in-editor | Not started |
| M3 | UI toolkit, tilemap editor, particles, input remapping, save games, export | Not started |
| M4 | A shipped game | Not started |
| M5 | 1.0 and a stability contract | Not started |

## Estimate

Roughly thirty months to 1.0 for a small team. Engine projects of this size
often take longer.
