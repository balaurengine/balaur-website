# Roadmap

## Where the engine stands

The core loop is in place: scene tree over an ECS, scripting in Luau and Rune
with hot reload, 3D and 2D physics, rendering (windowed and headless), audio,
input, UI, a working editor with play-in-editor, deterministic simulation,
reproducible pack export, and fused single-file executables. There is no
binary release yet; the engine builds from source.

## Next

1. `--!strict` type checking surfaced in editor diagnostics; palette-driven
   node search.
2. Editor: scene saving UX (autosave/undo), multi-scene tabs.
3. Prefabs/sub-scenes: a scene key instantiating another scene file.
4. Assets in packs (audio, textures) with content hashing.
5. `fixed_update` script callback and a fixed-tick mode where `update` sees a
   constant dt.
6. Parallel system execution inside the data plane, once profiling demands
   it.
