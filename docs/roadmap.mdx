# Roadmap

## Where the engine stands

The core loop is in place: scene tree over an ECS, scripting in Luau and Rune
with hot reload, 3D and 2D physics, rendering (windowed and headless),
animation with clip assets and tweens, a shared-asset layer, networking
(HTTP, websockets, and the Gamend backend), audio, input, UI, run-time
extensions, a working editor with play-in-editor and a clip timeline,
deterministic simulation, reproducible pack export, and fused single-file
executables. CI cross-compiles the headless engine to iOS, Android, and
WebAssembly on every push. There is no binary release yet; the engine builds
from source.

## Next

1. `--!strict` type checking surfaced in editor diagnostics; palette-driven
   node search.
2. Editor: scene saving UX (autosave/undo), multi-scene tabs.
3. Prefabs/sub-scenes. The asset layer landed, so a prefab is another
   registered asset type; what remains is the scene key that instantiates one
   and the rule for overriding properties on the instance.
4. Binary assets (audio, textures, fonts) in packs, with content hashing —
   TOML assets already pack and resolve by reference.
5. `fixed_update` script callback and a fixed-tick mode where `update` sees a
   constant dt.
6. Parallel system execution inside the data plane, once profiling demands
   it.
