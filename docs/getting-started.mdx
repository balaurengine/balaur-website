# Getting started

## Download

- [Download](/download) the editor. One binary is the editor, the CLI and the runtime.
- macOS: open `Balaur.app`. It opens the editor on `~/Balaur`, a starter project it makes on first launch.
- Windows and Linux: extract the archive. The `balaur` binary inside is the editor.

## A project

```bash
balaur new my-game
balaur edit my-game
```

```text
my-game/
├── project.toml        # [application] name, main_scene
├── scenes/main.toml    # the scene tree, in TOML
└── scripts/hello.rn    # a script attached to a node
```

## Run

Press Play in the editor, or run the project from a terminal:

```bash
balaur run my-game
```

## Edit a script

- Switch to the Script persona and open `scripts/hello.rn`.
- Save. The script reloads with its state kept.

<Clip name="scripting_live" alt="A script changed and saved while the scene runs, the new code live with the state kept" />

## Examples

The examples ship in the repository and play in the browser on the [Examples](/examples) page.

```bash
balaur edit examples/hello         # 3D: a spinning cube, a bouncing ball, a HUD label
balaur edit examples/angrynerds    # 2D: a slingshot game with 2D physics and widgets
balaur edit examples/rig           # a 2D skeleton: a skinned leg, an arm on two-bone IK
balaur edit examples/rig3d         # a 3D rig imported from a .glb
```

## From source

```bash
cargo run -p balaur_cli --features window -- edit my-game
```
