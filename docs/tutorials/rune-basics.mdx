# Rune basics

Scripts are written in [Rune](https://rune-rs.github.io/), a small dynamic
language with Rust's syntax and no types to declare. This page is what a
script needs from it; the [Rune book](https://rune-rs.github.io/book/) has
the rest.

## A script is free functions

The engine calls `pub fn` items by name and passes the instance first. What
you write to `this` is what you read on the next call.

```rust
// scripts/counter.rn
pub fn init(this) {
    this.frames = 0;
}

pub fn update(this, dt) {
    this.frames += 1;
}

pub fn draw_ui(this) {
    ui::label(format!("{} frames", this.frames));
}
```

Helpers need no `pub`; pass the instance along when they need it:

```rust
fn reset(this) {
    this.frames = 0;
}
```

## Values

```rust
let n = 3;                                   // integer
let x = 0.5;                                 // float
let s = "text";
let none = ();                               // nothing
let list = [1, 2, 3];                        // list
let table = #{ kind: "ball", radius: 0.5 };  // object
```

Integers and floats never mix: `n + x` is an error, and so is `dt * 2` where
`dt * 2.0` works. Anything a binding takes as a float is written `0.0`.

An object is read as `table.radius` or `table["radius"]`, and a new key is
assigned the same way. Lists have `push`, `len` and the rest of the usual
methods.

## Several values at once

A binding that returns more than one value returns a tuple; destructure it:

```rust
let (mx, my) = render::mouse_world_2d();
let (text, changed) = ui::text_field("name", "", #{});
```

A vector is one value with fields:

```rust
let p = this.node.position();
this.node.set_position(p.x, p.y + 1.0, p.z);
```

## Modules and nodes

Engine modules are reached with `::`; node operations are methods on a node
value. Constants a binding accepts are named, never spelled.

```rust
let t = engine::time();
let ball = scene::get_node("World/Ball");
physics3d::add_body(this.node, physics3d::BODY_DYNAMIC);
if input::just_pressed(input::KEY_SPACE) {
    this.node.get_node("../Target").set_position(0.0, 1.0, 0.0);
}
```

The [script API](../reference/script-api.md) lists every module, function
and constant.

## Control flow

```rust
if x > 1.0 { /* ... */ } else { /* ... */ }

for child in this.node.children() { /* ... */ }
for (i, child) in this.node.children().iter().enumerate() { /* ... */ }

let score = match kind {
    "pig" => 500,
    "block" => 50,
    _ => 0,
};
```

A lookup that finds nothing returns `()`; `value is Object` tells a script
whether a component read came back with something.

## Errors

A binding that fails raises an error and the call ends there. Wrap a call
that may fail in `script::attempt`, which returns `(ok, value)` — the
result, or the error message:

```rust
let (ok, clip) = script::attempt(|| assets::load("animations/missing.toml"));
if !ok {
    log::warn(format!("no clip: {}", clip));
}
```

## Splitting a script into files

`mod name;` at the top pulls in `name.rn` beside the script — from disk in a
dev run, from the pack when shipped:

```rust
// scripts/game.rn
mod util;

pub fn update(this, dt) {
    this.speed = util::clamp(this.speed + dt, 0.0, 10.0);
}
```

```rust
// scripts/util.rn
pub fn clamp(v, lo, hi) {
    if v < lo { lo } else if v > hi { hi } else { v }
}
```

`script::require("util.rn")` loads a file at run time instead and returns
its functions in an object. Both hot reload in place.

## Async

An entry point declared `async` can suspend on a result and resume at the
start of a later tick:

```rust
pub async fn init(this) {
    let r = task::wait(http::request("https://example.com")).await;
    log::info(format!("{} {}", r["status"], r["body"]));
}
```

See [Networking](../manual/networking.mdx) for the delivery model. One
limit: an async entry point cannot be paused by the debugger.
