The first commit: eight crates, one example. A node tree over an ECS, scenes
as TOML, scripts that hot reload with state kept, every subsystem a plugin.

{/* truncate */}

## What landed

- Nodes over an ECS. A game is a tree of nodes with scripts attached. Every
  node is an entity. Every subsystem (physics, rendering, audio, input, UI)
  is a plugin over the same data.
- Scenes as TOML. A scene file declares nodes. Plugins add keys: `body` and
  `collider` come from the physics crate.
- Hot reload. Saving a script swaps its code into the running game in
  milliseconds, with live state kept. Always on in dev mode.
- The editor is a project. `balaur edit` runs an editor written in the
  engine's own scripts. Editing an editor script hot reloads the editor.
- Export. `balaur export` precompiles scripts into a `.bpak`. `balaur play`
  runs from the bytecode.
- Headless by default. Without the `window` feature everything runs
  headless: tests, servers, CI.

```toml
[[nodes]]
name = "Ball"
position = [0.0, 6.0, 0.0]
script = "scripts/ball"
body = "dynamic"                                # from balaur_physics
collider = { shape = "ball", radius = 0.5 }     # from balaur_physics
```

Scripts were Luau in this commit; Rune replaced them. Cross-platform
determinism was a principle from this commit on.
[Principles](/docs/principles) has the list.
