Balaur is a 2D game engine for Rust. There is no code to download yet.

{/* truncate */}

Work so far has been design and measurement rather than implementation:
benchmarking scripting languages against a gameplay-shaped workload, comparing
scene-model designs, and checking performance targets against an existing
shipped game.

Some results changed the plan. The performance target set for the scripting
layer was about fifty times stricter than a real game needed. A renderer that
was assumed to require writing turned out to exist already. The scripting
language that scored best on the original target was not the one chosen once
the target was corrected.

A prototype now exists: Rune bindings for kiss3d and rapier, a node engine with
per-node hot reloading, an in-window editor, and a small game running on it.
