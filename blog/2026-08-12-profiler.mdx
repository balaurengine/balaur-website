The Profiler dock shows what each stage of the frame costs, and every run writes its log to a file.

{/* truncate */}

![The Profiler dock under a running game: the frame against its 16.7 ms budget, then update, scene_sync, render and last](/img/manual/editor_profiler.webp)

- `balaur run --timings` prints the same stages when a headless run ends.
- Each run writes `logs/run.log` in the game's user data folder and keeps the last five.
- A panic reaches the file before the process dies.
- `log::since(cursor)` reads the new lines from a script.
