The script API reference is read out of a booted engine: every module,
function, constant, component and asset type. CI fails when it drifts.

{/* truncate */}

- Every module, function and constant comes out of a running interpreter,
  because `input.KEY_SPACE` exists only after registration.
- The generated files are committed. A build whose output differs fails.
- The [script modules](/docs/reference/modules),
  [components](/docs/reference/components) and
  [assets](/docs/reference/assets) pages on this site are that output, one
  page per module, with what each function acts on.
- `rng`, `fs` and `toml` are declared language-neutrally, and the same seed
  gives the same sequence.
