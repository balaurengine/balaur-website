function, constant, component and asset type. CI fails when it drifts.

## What landed

- Read from a booted engine. Every module, function and constant comes out
  of a running interpreter. `input.KEY_SPACE` exists only after
  registration.
- Checked in CI. The generated files are committed. A build whose output
  differs fails.
- On this site. The [script modules](/docs/reference/modules),
  [components](/docs/reference/components) and
  [assets](/docs/reference/assets) references are that output, one page
  per module, with what each function acts on.
- `rng`, `fs` and `toml`. Declared language-neutrally. The same seed gives
  the same sequence.
