`text2d` and `text3d`: a sign in a scene and a label in a panel from one
bitmap, shaped the way the widgets are, with bidi, Arabic joining, CJK breaks
and the project's font chain.

{/* truncate */}

![Text in the world, one row per thing it does](/img/manual/text_overview.webp)

## What landed

- **`text2d`, `text3d`.** One component for both passes: the keys a label
  takes, plus `pixels_per_unit` to size it like a sprite. In 3D: `billboard`,
  `double_sided`, `depth_test`, `alpha_cut`.
- **Outline and shadow.** The same quads offset and tinted, each layer a
  thousandth of a unit in front of the last.
- **Markup.** `[b]`, `[i]`, `[color=…]`, `[wave]`. One mesh per colour, so a
  coloured word keeps its colour.
- **Bitmap fonts.** An AngelCode `.fnt` ships a pixel face as drawn: one
  glyph per character, no shaping, its page in the same atlas.
- **Crisp at any distance.** A block is rasterised at the size it covers on
  screen, in buckets 8.7% apart, geometric rather than linear.
- **Emoji.** A colour face per platform in the fallback chain.
- **Immediate calls.** `render.draw_text` and `draw_text_2d` for one frame,
  like a debug line. The Rig tool names bones with them.
- **`render.text_size`.** Measures against the project's and bundled faces
  only, never a system face, so a width written into state is the same on
  every platform. The glyph mesher reads the same faces, so a `kind = "text"`
  mesh and its colliders are too.
- **Edit in place.** Double-click a text node in the viewport.

```toml
[[nodes]]
id = "sign"
name = "Sign"
position = [0.0, 1.6, 0.0]
[nodes.text3d]
text = "A score on a sign"
font_size = 64
color = [1.0, 0.85, 0.3, 1.0]
pixels_per_unit = 110
outline_size = 3.0
outline_color = [0.1, 0.05, 0.0, 1.0]
```

No distance fields yet: a glyph is scaled by up to 8.7% between buckets.
