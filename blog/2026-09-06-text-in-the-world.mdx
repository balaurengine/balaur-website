`text2d` and `text3d`, shaped by the engine the widgets use. Outline and
shadow. Markup. Bitmap fonts. Editing in the viewport.

{/* truncate */}

## What landed

- **`text2d`, `text3d`.** One component for both passes: the keys a label
  takes, plus `pixels_per_unit`. In 3D: `billboard`, `double_sided`,
  `depth_test`, `alpha_cut`.
- **Outline and shadow.** The same quads offset and tinted, each layer a
  thousandth of a unit in front of the last.
- **Markup.** `[b]`, `[i]`, `[color=…]`, `[wave]`. One mesh per colour.
- **Bitmap fonts.** An AngelCode `.fnt`: one glyph per character, no
  shaping, its page in the same atlas.
- **Rasterisation.** A block is rasterised at the size it covers on screen,
  in geometric buckets 8.7% apart.
- **Emoji.** A colour face per platform in the fallback chain.
- **Immediate calls.** `render.draw_text` and `draw_text_2d` for one frame.
  The Rig tool names bones with them.
- **`render.text_size`.** Measures against the project's and bundled faces,
  never a system face: the same width on every platform. The glyph mesher
  reads the same faces, and a `kind = "text"` mesh and its colliders match
  everywhere too.
- **Edit in place.** Double-click a text node in the viewport.

```toml
[[nodes]]
id = "sign"
name = "Sign"

[nodes.transform]
position = [0.0, 1.6, 0.0]

[nodes.text3d]
text = "A score on a sign"
font_size = 64
color = [1.0, 0.85, 0.3, 1.0]
pixels_per_unit = 110
outline_size = 3.0
outline_color = [0.1, 0.05, 0.0, 1.0]
```

No distance fields: a glyph is scaled by up to 8.7% between buckets.
