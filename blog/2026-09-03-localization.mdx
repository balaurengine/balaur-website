One TOML file per language under `strings/`. Plural forms picked by the
locale's rules. A fallback locale. A missing key comes back as the key.

{/* truncate */}


## What landed

- Files. A key maps to a string, or to its plural forms. `{name}` in a
  string is replaced by the argument called `name`. An `n` argument picks
  the plural form by the locale's rules.
- Fallback. A key missing from the current locale is looked up in the
  project's fallback locale, one step. Missing from both, the key itself
  comes back.
- Switching. `strings::set_locale`, `strings::locales` for the project's
  locales, and `strings::system_locale` for the OS locale.

```toml
# strings/en.toml
"menu.play" = "Play"
"menu.items" = { one = "{n} item", other = "{n} items" }
```

```rune
let label = strings::tr("menu.items", #{ n: 3 });   // "3 items"
```

The `strings` module is in the
[script modules reference](/docs/reference/modules).
