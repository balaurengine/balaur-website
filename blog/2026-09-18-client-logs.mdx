## Log file

- Each run writes `logs/run.log` in the game's user data folder and keeps the last five runs as `run.1.log` and on.
- `[log] file = false` turns it off, and `[log] keep` sets how many runs stay, up to 50.
- A panic is written to the file before the process dies.
- In a browser the file is kept in the page's storage, and the next visit can read the run that crashed.
- `log::file()` answers where this run's file is.

## Reading and writting logs

- `log::info`, `log::warn` and `log::error` write a line tagged as a script's.
- The engine keeps the last 500 lines in memory, and the Output dock shows them, filtered by level and text.
- `log::since(cursor)` gives you all logs that happened since last cursor.
- `log::recent(n)` answers the last `n` lines.

```rune
pub fn init(this) {
    this.cursor = 0;
    this.errors = 0;
}

pub fn update(this, dt) {
    let read = log::since(this.cursor);
    for entry in read.entries {
        if entry.level == "error" {
            this.errors += 1;
        }
    }
    this.cursor = read.cursor;
}
```
