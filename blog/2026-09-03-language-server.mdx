`balaur lsp` speaks the Language Server Protocol and runs the editor's
Problems checks: missing scripts, prefabs, assets and shaders.

{/* truncate */}

- The checks catch a script or prefab a node names that does not exist, and
  an asset reference (a texture, a material, a mesh) that does not resolve,
  checked as written and as project-relative. They also catch a component
  missing what it expects beside it, and a shader that will not link, with
  file, line and column.
- The Problems dock re-checks every root script and the scene on save, and
  marks an error row with `×`.
- `balaur lsp` speaks LSP on stdin and stdout and calls the same
  `check_source` as the dock. It boots the project once and blocks on
  stdin, and a finding carries the end of its span.
- `script::check(path)` returns the same findings to a script.

```bash
balaur lsp my-game      # point your editor's LSP client at it
```

[Scripting](/docs/manual/scripting#hot-reload) covers what a save that
does not compile reports.
