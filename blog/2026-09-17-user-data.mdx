The editor now has a User data dock. It lists the files the open game keeps for its player, and opens saves and prefs as trees you can edit.

{/* truncate */}

![The User data dock with the prefs slot open](/img/manual/user_data_dock.webp)

- The dock lists the open game's user data folder, three folders deep, with each file's age.
- TOML and JSON files open as trees, and an edit writes the file back.
- Any other file shows its first 4000 characters, so `logs/run.log` reads there too.
- Reveal opens the folder or a file in the file manager.
- A game played in the editor writes to the same folder as the game run on its own, so a save made while playing opens here.

## In a plugin

- The dock is `editor/plugins/userdata.rn`, a plugin that calls `S.kit.files`.
- A plugin's own dock passes `root` for another folder, `only` for a list of file names, and `edit: false` to only read.

```rune
pub fn draw(S, k) {
    let files = S.kit.files;
    files(S, k, "saves", #{ only: ["slot1.toml"], edit: false });
}
```
