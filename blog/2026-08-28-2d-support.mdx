## What landed

- A rapier2d world. `body2d` and `collider2d` beside `body3d` and
  `collider3d`, over the same scene tree. rapier2d is Rapier's own 2D
  solver, shapes and determinism. Both worlds step on the fixed 60 Hz tick
  with Rapier's `enhanced-determinism` on and pass the same bit-for-bit
  test. The 3D path is unchanged.
- 2D drawing. Shapes draw in z order.
- The editor. A scene with 2D components gets a 2D grid, a pan-and-zoom
  camera and a 2D gizmo: drag an axis, a plane, or the ring.
- examples/angrynerds. A slingshot, towers, and pigs with glasses, in one
  scene and one script.

```toml
[[nodes]]
name = "Bird"
transform = { position = [-8, 2.2, 0] }
body2d = "kinematic"

[nodes.shape2d]
kind = "circle"
radius = 0.4
```
