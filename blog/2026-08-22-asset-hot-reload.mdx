Textures, models, fonts and sounds reload when saved. Assets carry stable
`id://` references. Renaming a file rewrites every reference to it.

{/* truncate */}

- A saved texture, model, font or sound moves the asset generation, and
  every node built from one is rebuilt. Scripts reload the same way.
- An `id://` reference resolves through `assets/index.toml` and survives a
  move.
- `assets.rename` in a script, or a rename in the Assets dock, rewrites
  every reference to the moved file across scenes and assets.
- The dock browses, filters, makes folders, renames and deletes. A card
  selects on the first click and opens on the second.
- An import runs on its own thread, so the editor keeps drawing. Several run
  at once, listed in the top right with one bar under them.

  ![The editor importing two files at once, one finished and one part way through](/img/manual/editor_import.webp)

```toml
[nodes.sprite]
texture = "id://hero"      # assets/index.toml says which file that is
```
