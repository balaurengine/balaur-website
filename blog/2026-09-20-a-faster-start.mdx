The editor opens in half the time it did, and the shell behind the splash is already the one you keep.

![The editor's splash while it boots](/img/blog/editor_splash.webp)

## Compiled scripts are kept

- A dev run writes each unit it compiled under `units/` in the project's user data directory, one file per script, and reads it back the next time.
- The editor is 32,653 lines of Rune. Compiling them was 155 ms of every start, and reading them back is 25 ms.
- `balaur edit examples/hello --offscreen --frames 1` went from 370 ms to 183 ms on an Apple M1.
- A generated project of 60,000 lines boots in 35 ms instead of 201 ms.
- A hit is checked against every source file's hash, the engine binary, and the addons mounted into the compile. Anything else compiles.
- The kept unit carries its debug info, so breakpoints and error spans read as they did.

## The shell settles before you see it

- Every box in the shell is read back a pass after it was written, so the first pass places it and the next corrects it.
- The splash used to come off during that, and the tool rail, the dock chips and the inspector's columns moved once more.
- It now holds until two passes in a row write no box and nothing is still easing.

## What a boot costs

- `--timings` prints a boot table before the frame table: engine, plugins, scripts compiled or cached, project, renderer, and the wait for the first frame.
- Every number above was read off it.
