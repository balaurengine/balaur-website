The editor runs in a browser tab, on the WebAssembly module the
[examples](/examples) play on. The project lives in IndexedDB. Export writes a
pack.

{/* truncate */}


## What landed

- Play. The examples run in the tab on WebGPU.
- The editor. [balaurengine.org/editor](/editor) opens on an example or on
  a local folder, and returns the project as a zip.
- Persistence. The project is kept in IndexedDB, textures and sounds
  included, and survives a refresh.
- Export. A `.bpak`, or a web bundle zipped beside the running module.
  Native targets need a linker.
- A lazy shell. `ui::set_lazy` runs the shell pass only on input, a log
  line, a reload or an animation. An idle frame went from 7.2 ms to 4.8 ms.

## Not in the tab

An account and a project kept on Gamend, native export, a linker and a
signing toolchain, and the debugger.
[PLAN-web-editor.md](https://github.com/balaurengine/balaur/blob/main/docs/PLAN-web-editor.md)
has the order. [Build size](/docs/manual/build-size) has the module's weight
and how to make a smaller one.
