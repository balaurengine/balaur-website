0.1.0 is tagged, and it is pre-alpha. A 2D and 3D engine on a fixed 60 Hz
step, with an editor built from the engine's own widgets and Rune scripts that
reload in milliseconds. The [roadmap](/docs/roadmap#0.1) has the fifteen rows
it closes.

<Clip name="balaur-0-1-0" alt="Balaur 0.1.0 end to end: a recorded run played back with nobody at the mouse, the editor, a Rune script reloaded while the scene runs, Rapier colliders, the input overlay, a keyed animation, and a WESL shader relinked in place" />

## Features

- **Determinism.** A fixed 60 Hz step, and a digest per tick that CI compares
  across operating systems. Record, replay, roll back.

  <Clip name="determinism_replay" alt="Play records; the bird flies; stop. The session opens from the Session dock and the bird flies again with nobody at the mouse" />

- **The editor.** Tabbed, resizable docks built from the engine's own
  widgets, so the editor is a Balaur application.

  <Clip name="scenes_inspect" alt="Selecting nodes in the tree; the inspector follows, a scale is dragged, and undone" />

- **Rune scripting.** One deterministic language, hot reload in milliseconds, and a debugger over the Debug Adapter Protocol.

  <Clip name="scripting_live" alt="A script changed and saved while the scene runs, the new code live with the state kept" />

- **Rapier in 2D and 3D.** Bodies, joints, character controllers, queries and
  every collider shape rapier has, behind one script API.

  <Clip name="physics_collapse" alt="The Physics persona's collider overlays over the towers of examples/angrynerds, then play and a shot at them" />

- **Input.** Actions over keyboard, mouse, gamepads and touch, and an overlay
  that draws them while a scene plays.

  <Clip name="input_overlay" alt="The editor's input overlay while examples/hello plays: key chips, the actions they drive, the pointer and a click ripple" />

- **Animation.** Clips and tweens, skeletons skinned on the GPU, painted
  weights, IK and retargeting.

  <Clip name="animation_key" alt="The Animate persona: scrubbing the clip, posing the thigh bone, keying it, and playing" />

- **Rendering.** Sprites, tile maps, 2D lights and shadows, `light3d` and an
  `environment`, PBR, WESL shaders, and sixteen primitives.

  <Clip name="shader_preview" alt="A material in the inspector, its shader open in the code editor, the UV channel drawn instead of the picture, and a save that relinks the sprite in place" />

- **Export.** Native and web targets with a size report, iOS and Android, and
  the editor itself in a browser tab.

  ![The Export sheet: the ios, android, macos-universal, windows and web targets](/img/manual/export_sheet.webp)

## Where to get it

[Download](/download) has a build per platform, and `balaur update` replaces
an install. Pre-alpha means the APIs still move between versions; what 0.2
adds is on the [roadmap](/docs/roadmap#0.2).
