## What landed

- Rollback. A snapshot restores a tick and the deterministic simulation
  re-runs the same inputs. Node ids are stable across spawns and re-runs.
  Scripts see `rollback::input` and `rollback::is_resimulating`.
- A digest per tick. A peer publishes a tick's hash once every player's
  input for it has arrived. A desync names the tick.
- One `Transport`. WebSockets, and QUIC datagrams through
  `balaur_webtransport`: a lost input costs a misprediction. `balaur_http`,
  `balaur_websocket` and `balaur_webtransport` are one crate each, behind
  their own features.
- Link faults. Delay, jitter and datagram loss on every session link, set
  from the editor's settings.
