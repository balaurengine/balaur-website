Rune is the scripting language. Each subsystem declares its bindings once,
against a language-neutral seam, and every component on a node is a handle
the script can call.

{/* truncate */}

- `balaur_script` is the neutral contract: a binding is a name, typed values
  and a function. A backend implements `ScriptHost`. Physics, input, render,
  audio and UI declare their bindings there.
- `balaur_script_rune` is the host, picked by `language` in `project.toml`.
  Each node gets one object, and `pub fn update(this, dt)` runs on it. What
  a script writes to `this` the host reads next frame.
- The twenty-seven node operations are one list of neutral functions taking
  the node first, and a backend adds its own call sugar.
- `pub fn exports()` returns a script's defaults. The scene overrides only
  what it changes, and the inspector lists them per node.
- Each component on a node is a field on the node. The field's methods are
  the owning module's functions with the node filled in, plus `get()`,
  `set(table)`, `has()` and `remove()` on all of them.

```rune
pub fn exports() {
    #{ speed: 2.0 }
}

pub fn fixed_update(this, dt) {
    // every function that drives body2d, spelled from the node
    this.node.body2d.apply_impulse(this.speed * dt, 0.0);
}
```

[Scripting](/docs/manual/scripting) has the model.
