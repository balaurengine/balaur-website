`engine::timings()` reports the last frame as a span per stage. A Profiler
dock draws it against the 16.7 ms a 60 Hz frame has. `--timings` for a
headless run.

{/* truncate */}


## What landed

- Stages. `first`, `pre_update`, `update`, `fixed_update`, `scene_sync`,
  `last`, and physics as `physics3d/step` and `physics2d/step`: the cost
  of each this frame, in order.
- The dock. Open it while playing and every frame redraws the bars. A
  stage past its share of the budget stands out.
- Headless. `balaur run my-game --timings` prints the same stages when the
  run ends: mean, worst, and share of a 60 Hz frame.
- Scripts. `engine::timings()` returns the same table.

```bash
balaur run examples/angrynerds --headless --fixed-tick --frames 600 --timings
```

[The editor](/docs/manual/editor#docks-palette-themes) lists the docks.
