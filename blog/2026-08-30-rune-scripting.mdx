Rune as the scripting language. Bindings each subsystem declares once,
against a language-neutral seam. A handle per component on a node.

{/* truncate */}


## What landed

- The seam. `balaur_script` is the neutral contract: a binding is a name,
  typed values and a function. A backend implements `ScriptHost`. Physics,
  input, render, audio and UI declare their bindings there.
- Rune. `balaur_script_rune` is the host, picked by `language` in
  `project.toml`. One object per node, `pub fn update(this, dt)`. What a
  script writes to `this` the host reads next frame.
- The node API. Twenty-seven node operations are one list of neutral
  functions taking the node first. A backend adds its call sugar.
- Exported properties. `pub fn exports()` returns defaults; the scene
  overrides only what it changes; the inspector lists them per node.
- Component handles. Each component on a node is a field on the node. The
  field's methods are the owning module's functions with the node filled
  in. `get()`, `set(table)`, `has()` and `remove()` on all of them.

```rune
pub fn exports() {
    #{ speed: 2.0 }
}

pub fn fixed_update(this, dt) {
    // physics2d::apply_impulse(this.node, ...), spelled from the node
    this.node.body2d.apply_impulse(this.speed * dt, 0.0);
}
```

Rune is the only host. [Scripting](/docs/manual/scripting) has the model.
